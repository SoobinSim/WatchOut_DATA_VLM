# Data Utilities

WatchOut! 프로젝트의 AI-Hub 데이터 다운로드 확인, 분할 ZIP 병합 및 압축 해제를 위한 유틸리티 모듈입니다.

## 1. 목적

AI-Hub에서 다운로드한 영상 및 라벨 파일을 전처리 가능한 형태로 준비합니다.

특히 분할 다운로드된 파일을 병합하고, ZIP 내부 경로 문제를 처리하여 원본 MP4와 XML 파일을 확보합니다.

## 2. 주요 스크립트

### `inspect_normal_download.py`

**다운로드 파일 구조 확인**

- AI-Hub 238-1 다운로드 폴더 탐색
- 파일 개수 확인
- 확장자별 파일 수 집계
- 다운로드된 파일 경로 및 이름 출력

분할 ZIP을 병합하기 전에 실제 다운로드 구조를 확인하는 용도로 사용합니다.

### `check_normal_purchase.py`

**정상 구매 영상·XML 탐색**

- AI-Hub 구매행동 데이터 폴더 탐색
- MP4 및 XML 파일 수 확인
- 영상·라벨 파일명 기반 매칭 현황 출력

압축 해제 이전에는 MP4 및 XML 개수가 0으로 출력될 수 있습니다.

### `merge_normal_purchase.py`

**정상 구매 데이터 분할 ZIP 병합**

AI-Hub에서 다운로드한 `.zip.part*` 파일을 원래의 ZIP 파일로 병합합니다.

분할 파일명의 `part` 뒤 숫자는 파일 시작 위치에 해당하므로 숫자 순서대로 병합합니다.

**처리 대상**
- 구매행동 원천데이터(VS)
- 구매행동 라벨링데이터(VL)

**주요 출력**
- `VS_02.구매행동_04.구매.zip`
- `VL_02.구매행동_04.구매.zip`

기존 분할 파일은 삭제하지 않습니다.

### `extract_normal_purchase.py`

**정상 구매 ZIP 압축 해제**

- 병합된 원천데이터 및 라벨링데이터 ZIP 탐색
- ZIP 내부 파일 경로 처리
- MP4 영상 및 XML 라벨 추출
- 추출 후 파일 개수 출력

실제 데이터에서는 ZIP 내부 경로가 `/`로 시작하는 경우가 있어, 이를 처리하도록 수정했습니다.

## 3. 처리 순서

```text
AI-Hub 데이터 다운로드
         |
         v
inspect_normal_download.py
         |
         v
merge_normal_purchase.py
         |
         v
extract_normal_purchase.py
         |
         v
check_normal_purchase.py
         |
         v
데이터 선별 및 전처리
```

## 4. 주요 파일 형식

| 형식 | 설명 |
|---|---|
| `.zip.part*` | 분할 다운로드 파일 |
| `.zip` | 병합된 압축파일 |
| `.mp4` | CCTV 원천 영상 |
| `.xml` | 영상 주석 및 행동 라벨 |

## 5. 주의사항

- ZIP 병합 전에 동일 파일명의 모든 분할 조각이 확보되었는지 확인해야 합니다.
- 병합 및 압축 해제 시 별도의 저장 공간이 필요합니다.
- 병합 ZIP과 추출 데이터가 정상적으로 생성되기 전에는 원본 분할 파일을 삭제하지 않는 것이 좋습니다.
- 원본 영상, XML 및 압축파일은 공개 GitHub 저장소에 업로드하지 않습니다.
- 스크립트 내부의 로컬 파일 경로는 사용자 실행 환경에 맞게 설정해야 합니다.
