# Data Collection & Selection

WatchOut! 프로젝트에 사용할 CCTV 영상 및 라벨 데이터를 선별하고 데이터셋을 구성하는 모듈입니다.

## 1. 목적

AI-Hub에서 제공하는 이상행동 및 구매행동 데이터를 대상으로 MP4 영상과 XML 라벨을 매칭하고, 이후 전처리 및 VLM 실험에 사용할 데이터셋을 구축합니다.

## 2. 주요 스크립트

### `select_dataset_300.py`

**이상행동 데이터 300개 선별**

- AI-Hub 238-2 Validation 데이터 사용
- 절도(Theft), 파손(Damage), 흡연(Smoking), 유기(Dumping) 유형 선별
- 각 유형별 75개씩 총 300개 영상 구성
- 영상에 대응되는 XML 라벨 함께 관리
- 데이터셋 메타데이터 생성

초기에는 각 유형별 10개씩 총 40개 영상으로 데이터 처리 과정을 검증한 뒤 300개로 확장했습니다.

**주요 결과**

| 행동 유형 | 영상 개수 |
|---|---:|
| Theft | 75 |
| Damage | 75 |
| Smoking | 75 |
| Dumping | 75 |
| **Total** | **300** |

### `select_normal_150.py`

**정상 구매행동 영상 선별**

- AI-Hub 238-1 Validation 구매행동 데이터 사용
- MP4 영상과 XML 라벨 파일명 기반 매칭
- 재현 가능한 랜덤 시드를 사용하여 영상 선별
- 영상과 XML을 별도 폴더에 복사
- 정상 구매행동 메타데이터 CSV 생성

선별 목표는 150개였으나, 실제 매칭된 영상 수에 따라 최종 100개를 구성했습니다.

**주요 결과**
- 정상 구매행동 영상: 100개
- 데이터 유형: `normal_purchase`
- 메타데이터: `normal_metadata_150.csv`

파일명에 `150`이 포함되어 있으나 실제 데이터는 100개입니다.

## 3. 데이터셋 구성 결과

| 데이터 구분 | 영상 수 |
|---|---:|
| 이상행동 | 300 |
| 정상 구매행동 | 100 |
| **전체** | **400** |

## 4. 후속 처리

선별된 영상 및 XML은 `preprocessing/` 모듈에서 프레임 추출과 이벤트 구간 분석에 사용합니다.

## 5. 주의사항

- 정상 구매행동은 AI-Hub 구매행동 유형을 기준으로 선별한 데이터이며, 이상행동 부재가 별도로 검증된 정답 데이터는 아닙니다.
- AI-Hub 원본 영상과 XML은 공개 저장소에 포함하지 않습니다.
- 스크립트 실행 시 로컬 데이터 경로 설정이 필요합니다.
